= Purpose

indexterm:[workflow, data collection]
indexterm:[workflow, record authoring]

The purpose of this deliverable is to describe the current
state of how DeX artifacts are researched,
authored, and validated,
with attention to manual effort and sources of variability.
This report also provides a baseline for improving efficiency
across each process for future scaling of DeX artifacts.
