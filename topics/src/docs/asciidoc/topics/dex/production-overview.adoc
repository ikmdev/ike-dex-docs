= Overview of DeX Production

indexterm:[device data, IVD device]
indexterm:[knowledge exchange, Komet]
indexterm:[knowledge exchange, DeX v2 model]
indexterm:[organizations, CLIA]
The DeX pilot selected 20 in vitro diagnostics (IVDs) devices
from device information provided from a partnered,
high-complexity Clinical Laboratory Improvement Amendments
(CLIA)-certified laboratory.
Specific performance attributes were selected and collected for
each IVD device and modeled in Komet,
an IKE tool that supports authoring DeX records.
The pilot demonstrated a baseline process for authoring an
initial set of DeX records;
however, as more complex laboratory IVD devices were investigated,
the pilot exposed challenges described in the data gathering
and authoring processes.
The team aims to improve these processes as we move towards an
extensible version two (v2) DeX model with the goal of reducing
manual effort and improving consistency across records.
