= Validation of DeX Data Elements

indexterm:[workflow, SME validation]
indexterm:[terminology, LOINC]
indexterm:[terminology, SNOMED CT]
Validation with a SME is built into each step of data collection,
so the SME reviews information as it is gathered.
Specifically,
the laboratory device SME confirms that the GUDID and 510(k)
records describe the same IVD device,
fills gaps in decision summaries,
supplies or confirms package insert details,
and identifies associated devices when there is no clear description.
The SME also validates LOINC® and SNOMED-CT® codes,
confirming the information is current and accurate for the IVD
device version under review.
