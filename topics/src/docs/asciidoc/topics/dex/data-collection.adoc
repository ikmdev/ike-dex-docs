= Current State of DeX Data Collection & Research

indexterm:[workflow, data collection]
indexterm:[workflow, SME validation]
indexterm:[device data, IVD device]
Gathering data for a DeX record currently depends on manual
parsing across disparate sources of IVD device information.
The process is described by three main activities:
identifying the IVD device and associated devices,
pulling information from available data sources,
and validating with a subject matter expert (SME).
