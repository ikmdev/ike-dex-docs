[[model-predicate-device-pattern]]
= Predicate Device Pattern

indexterm:[device data, predicate device]
indexterm:[device data, GUDID]
indexterm:[knowledge exchange, Semantic]
Many devices are submitted for FDA approval based on a
predicate device.
This Pattern indicates the predicate device when applicable.
The reference component for a Predicate Device Semantic is the
Device Concept and the field value is a Component Set that
contains the relevant predicate device Concept from the GUDID dataset.
