= Measuring Range Pattern

indexterm:[device data, measuring range]
indexterm:[knowledge exchange, Semantic]
indexterm:[terminology, UCUM]
If the results returned by the device for a given test can be
represented as a numeric range,
extend the Results Description Semantic using this Pattern.
The information in this Pattern represents the reportable range for a device.
If the values fall outside this range,
they are considered invalid.

The reference component will be a Test Performed Semantic.
