[[model-associated-devices-pattern]]
= Associated Devices Pattern

indexterm:[device data, associated device]
indexterm:[device data, GUDID]
indexterm:[knowledge exchange, Semantic]
If multiple devices,
such as reagents,
are necessary to support the primary device performing the test,
utilize this Pattern to represent those relationships.
The reference component for an Associated Devices Semantic is
the Device Concept and the field value is a Component List that
contains each relevant associated Device Concept from the GUDID dataset.
