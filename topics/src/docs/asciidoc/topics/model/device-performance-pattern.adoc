= Device Performance Pattern

indexterm:[device data, device performance]
indexterm:[diagnostic accuracy, sensitivity]
indexterm:[diagnostic accuracy, specificity]
indexterm:[knowledge exchange, DeX starter data]
This Pattern captures information on a device’s performance,
most commonly sensitivity and specificity metrics which are
reported as confidence intervals.
Not every device will have a Device Performance Semantic but
this Pattern allows a DeX author to input this information when present.
The reference component is a Test Performed Semantic.
