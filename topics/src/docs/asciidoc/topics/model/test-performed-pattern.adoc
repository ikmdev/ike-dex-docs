= Test Performed on Specimen Pattern

indexterm:[device data, test performed]
indexterm:[terminology, LOINC]
indexterm:[terminology, SNOMED CT]
indexterm:[terminology, UCUM]
This Pattern describes a single test that the device is capable of performing.
The reference component is the device Concept.
Test Performed Semantics should be unique at the
analyte-specimen level.

indexterm:[device data, limit of detection]
A single test may require the creation of multiple Test
Performed Semantics if the output can be represented using
multiple units of measure or if different specimens have
different detection limits for the same unit of measure.

There is a unique Test Performed Semantic for each
analyte-specimen pair.
This allows related information including reference ranges,
limits of detection and units of measure to be associated to
the correct analyte and specimen.
