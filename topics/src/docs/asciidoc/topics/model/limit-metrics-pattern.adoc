= Limit Metrics Pattern

indexterm:[device data, limit metrics]
indexterm:[device data, limit of detection]
indexterm:[knowledge exchange, Semantic]
This Pattern is used to indicate any associated limits of detection,
quantitation or blank.
Tests may have one or many of these limits.
A Limit Metric Semantic should be created for each relevant limit.
The type of limit is indicated within a field in the Semantic.
The reference component is a Test Performed Semantic and every
Test Performed Semantic should have at least one Limit Metrics Semantic.
