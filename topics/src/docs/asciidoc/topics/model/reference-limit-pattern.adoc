= Reference Limit Pattern

indexterm:[device data, reference limit]
indexterm:[knowledge exchange, Semantic]
indexterm:[terminology, SNOMED CT]
This Pattern is used when a test with quantitative results has
a reference limit with only an upper or lower bound rather than a range.
Reference limits indicate a percentile so the Pattern includes
a field to indicate this.

The reference component is the Test Performed Semantic.
