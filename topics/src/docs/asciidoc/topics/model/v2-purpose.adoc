= Purpose

indexterm:[knowledge exchange, DeX v2 model]
indexterm:[device data, IVD device]
indexterm:[device data, GUDID]
indexterm:[knowledge exchange, Pattern]
This document delivers the refined data model for DeX,
the extension that gives meaning to laboratory devices,
beginning with in vitro diagnostic (IVD) devices catalogued in GUDID.
This document details revisions to existing data elements,
identifies new elements and where their Patterns stand in
version 2 (v2),
and records what changed from the previous DeX model version.
