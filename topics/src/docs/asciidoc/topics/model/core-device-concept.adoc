= Core Device Concept

indexterm:[device data, GUDID]
indexterm:[device data, FDA product code]
indexterm:[knowledge exchange, Concept]
The Core Device Concepts for DeX information are sourced from GUDID.
The Device Concept always contains a Fully Qualified Name,
Unique Device Identifier (UDI) (GS1),
and an Is-A relationship to its FDA Product Code(s).

indexterm:[knowledge exchange, Semantic]
The existing information may or may not align with the
information provided in the gathered DeX data for a Device.
If it does not align,
the DeX author should consider adding:

* A Device Extension specific name as an “Other Name” as a Description Semantic
* Additional Device Identifiers or FDA PreMarket Submission Codes as Identifier Semantic(s)
* Additional Is-A relationships to FDA Product Codes as part of the Stated Definition Semantic
