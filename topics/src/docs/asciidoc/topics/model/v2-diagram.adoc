The change summary from the previous iteration of the DeX model
to v2 can be summarized as:

* *A standard identity scaffold for the Device Concept.*
The model now carries Semantics for Descriptions
(Fully Qualified Name [FQN] and device names),
Identifiers (Primary Device Identifier [DI] and premarket submission numbers),
and Stated Definition Semantics (Is-A links to FDA product codes).
* *Four Patterns added to the diagram:*
Predicate Device,
Measuring Range,
Limit Metrics,
and Reference Limit.
* *The Limit Metrics Pattern now contains the Detection Limit*,
as a better representation to support limits of detection (LoD),
limits of quantitation (LoQ),
and limits of blank (LoB).
* *Units of measure are now controlled Concepts.*
Example Unified Code for Units of Measure (UCUM) Units changed from a free-text string
to a SNOMED-CT® Concept on the Test Performed and Population Reference Range Patterns.
* *Reference intervals are modeled as two distinct cases:*
a two-sided Population Reference Range,
or a one-sided Reference Limit tied to a percentile.
A new decision step in the model,
represented below Results Description (previously Allowed Results) on the diagram,
routes quantitative results to the correct Pattern.
* *Additional Interpretation field for Population Reference Range.*
The interpretation field allows the DeX model to support multiple reference ranges
for a device that differ by interpretation.

and v2 diagrams on the v2 layout.
Green outlines mark elements added to the model,
and blue outlines mark revised fields or labels.
