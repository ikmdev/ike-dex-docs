= Refined Data Model Documentation

indexterm:[knowledge exchange, Pattern]
indexterm:[knowledge exchange, Komet]
indexterm:[terminology, SNOMED CT]
indexterm:[terminology, LOINC]
indexterm:[device data, GUDID]
This section documents DeX v2 Pattern by Pattern and provides
the purpose of the Patterns.
To model DeX,
the working dataset must contain SNOMED-CT® International Edition,
LOINC®, and GUDID.
Where a source Concept cannot be found (for example,
a result value with no SNOMED-CT® code),
the DeX author should create it in Komet as an extension
Concept rather than overloading an existing one that may have a
differing meaning or intention.
