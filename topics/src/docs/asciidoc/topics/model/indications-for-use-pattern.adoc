= Indications for Use Pattern

indexterm:[device data, indication for use]
indexterm:[knowledge exchange, Pattern]
indexterm:[knowledge exchange, Semantic]
This information describes the patient population a device serves,
or why a test using the device might be ordered.
This information is represented using the Indications for Use Pattern.
The reference component is the Device Concept,
and the Field Value will be a string with the indication for use.
When a Device has multiple indications for use,
each is represented by a separate Semantic.
