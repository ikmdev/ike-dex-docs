= Results Description Pattern

indexterm:[device data, allowed results]
indexterm:[terminology, SNOMED CT]
indexterm:[knowledge exchange, Komet]
This Pattern expresses the set of allowable results that can be
returned by the Device.
The reference component will be a Test Performed Semantic.
The allowed results are expressed as SNOMED-CT® qualifier values,
and the field value is a Component Set.
The values for this Semantic are sourced from the DeX Results
Description (SNOMED-CT®) source data field.

If a test does not return results that can be captured using an
existing SNOMED-CT® code,
we recommend using Komet to author the necessary result
Concepts as extensions to SNOMED-CT®.
