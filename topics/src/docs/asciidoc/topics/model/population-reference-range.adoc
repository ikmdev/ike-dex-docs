= Population Reference Range Pattern

indexterm:[device data, reference range]
indexterm:[knowledge exchange, Semantic]
indexterm:[terminology, SNOMED CT]
This Pattern represents the reference range for quantitative
test results for a given population.
The reference range will vary by population and laboratory.
The reference component is the Test Performed Semantic.
