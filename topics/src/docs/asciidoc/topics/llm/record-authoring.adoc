= LLM-supported Record Authoring

indexterm:[knowledge exchange, Komet]
indexterm:[automation, Komet Assistant]
indexterm:[knowledge exchange, Concept]
One recent Komet feature is a built-in LLM chat window,
the Komet Assistant,
that supports authoring of content by proposing draft versions
of an IVD device Concept not yet existing in the starter data,
such as the analyte,
target, and device company Concepts.
Figure 1 shows the output for the following prompt that
requests the Komet Assistant to generate Concepts required for
the Xpert® Xpress CoV-2 DeX Record:

_“Create Concepts for the following:_

* _Analyte: SARS-CoV-2 (Analyte)_
* _Targets: SARS-CoV-2 Nucleocapsid protein (N) gene (Target), SARS-CoV-2 Envelope protein (E) gene (Target), SARS-CoV-2 RNA-dependent RNA polymerase protein (RdRP) gene (Target)_
* _Device Labeler: CEPHEID”_

indexterm:[knowledge exchange, Pattern]
indexterm:[knowledge exchange, Semantic]
As shown in the Figure,
the Komet Assistant generates a table of proposed attributes
for the Concepts of this IVD device’s analyte,
targets, and device labeler,
including its suggested Fully Qualified Names (FQNs) and parent Concepts.
The user can review,
make edits in the chat,
and confirm or decline the proposed attributes.
Once confirmed,
the Komet Assistant creates draft versions of these Concepts,
which the user reviews in the Komet Assistant window before
publishing the content to the knowledge base.
The Komet Assistant can also create DeX Patterns and Semantics.
In Figure 2,
the Komet Assistant proposes a Test Performed Semantic for the
Xpert® Xpress CoV-2 device,
incorporating the previously created Concepts for the device company,
analyte, and targets as well as Concepts from LOINC®,
SNOMED-CT® and GUDID.

The Komet Assistant applies the same structure to each Concept,
Pattern, and Semantic drafts,
minimizing variation between authors.
Similarly,
for any changes to an existing Concept,
Pattern, or Semantic or new content created by the Komet Assistant,
the Review Changes Window shows a granular view of additions and edits,
supporting version control and human-in-the-loop review.
The automation of these steps significantly reduces manual
effort and the interpretation required during authoring,
shifting the team’s focus to validation and review of the
resulting content.
